# Session 012 — Phase 3 (1/8): API-first + CLI + stack detail

**Full routine `29 passed, 0 failed`** (layer 1: 6, layer 1.5 CLI: 10,
layer 2: 12, layer 3: 1). What shipped:

- `internal/api/` — typed peer API contract (CONCEPT: API-first).
  One Go struct per response shape; every handler marshals these
  (no more ad-hoc `map[string]string`). Hand-written OpenAPI 3.1
  document served at `GET /openapi.json` (+ `/openapi.yaml` stub);
  `internal/api/openapi_test.go` is the drift guard — it fails when
  the document names a field the Go struct doesn't (and vice
  versa). Live `jsonschema` validation of real peer responses
  passed during the session.
- `web/scripts/gen-types.mjs` — generates `web/src/api/types.ts`
  from the live contract; `npm run gen:check` fails on drift and
  is wired into `scripts/test.sh` layer 1.5.
- CLI `cmd/ferriage` — stacks / peer / deploy / export / import /
  version, `--peer` (or `$FERRIAGE_PEER`), `--json` prints the
  peer's JSON verbatim. Ships in the peer image as
  `/usr/local/bin/ferriage` (deploy/Dockerfile). 5 Go tests
  against a fake typed peer.
- `web/src/components/StackDetail.tsx` — stack detail view:
  services, working dir, Deploy / Export snapshot / Import
  snapshot (file picker), health-gate result inline, errors.
  Cards are now clickable (`onOpen`); list layout unchanged
  (layer-3 baseline 0.09% drift). Detail baseline committed as
  reference: `tests/baselines/ui-2026-11-20-stack-detail.png`.
- `scripts/test.sh` layer 1.5 — CLI e2e against an ephemeral
  peer: gen:check, deploy, stacks --json, export/import round
  trip with volume surviving, non-zero exit on missing stack.

Gotchas:

- `adopt.Stack` and `api.Stack` are structurally identical but
  distinct types; `stacks` handler maps field-by-field
  (`toAPIStack`) — the drift test keeps them honest.
- The peer adopts *host* containers by label, so dev screenshots
  show whatever compose projects happen to run on the box.
- `--json` output is pretty-printed (2-space indent): grep
  patterns need `"name": "` with a space.
- `scripts/test.sh` had a duplicated layer-2 cleanup line ending
  in `i: command not found` after the smoke — caught by the full
  run, fixed the same session (no behavior change; the cleanup
  already ran inside layer 2).
