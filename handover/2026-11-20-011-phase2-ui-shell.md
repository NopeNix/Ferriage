# Session 011 — Phase 2: UI shell + Zone-1 OIDC gate + baseline

**Phase 2 done.** Full routine `19 passed, 0 failed`
(layer 1: 6, layer 2: 12, layer 3: 1). What shipped:

- `web/` — Vite + React 19 + TS + Tailwind 4 + shadcn components
  (hand-written: button/badge/card; no CLI shenanigans). Stack list
  + peer badge + offline/error states, all behind typed `api/`
  (mirrors the peer's JSON shapes by hand until Phase 3's typed API).
- `web/bff/` — BFF: serves `dist/`, proxies `/api/*` to the peer,
  owns the Zone-1 gate (ADR 0004). `auth.mjs`: OIDC code+PKCE via
  `openid-client` v6, HMAC session cookie (8h, HttpOnly/SameSite=Lax/
  Secure-when-TLS), CSRF on writes, rate limits (login 10/min,
  callback 20/min, API 600/min). 8 `node:test` unit tests.
- `deploy/Dockerfile.ui` — UI container (`node:24-alpine`, dist +
  `npm ci --omit=dev` for openid-client).
- `deploy/dev/dex.yml` — dev IdP (Dex v2.41.1, ADR 0003).
- `scripts/png-diff.mjs` + layer 3 in `scripts/test.sh`: headless
  Chrome screenshot of the live UI, pixel-diff vs
  `tests/baselines/ui-2026-11-20-stack-list.png` (2% tripwire).
  `tests/baselines/ui-2026-11-20-login.png` (Dex picker) is
  reference-only, not diffed.
- OIDC E2E proven against the live stack: login → Dex password
  (`operator@ferriage.dev`) → approval → BFF callback → session
  cookie → `/auth/me` → authenticated `/api/stacks` → CSRF-less
  POST 401.

Gotchas that cost rounds:

- **Dev IdP switched Zitadel→Dex** (ADR 0003): Zitadel v4 wants
  CockroachDB + masterkey. Dex is one container + static YAML.
  Prod IdP stays a separate decision.
- **`openid-client` v6**: `serverMetadata`/`clientMetadata` are
  *methods*, not properties; `discovery()` needs
  `{ execute: [allowInsecureRequests] }` *in the discovery call
  itself* for `http://localhost` issuers (else "only requests to
  HTTPS are allowed"). `authorizationCodeGrant(config, url,
  { expectedState, expectedNonce, pkceCodeVerifier })` — read the
  `.d.ts`, don't guess.
- **Dex issuer**: must be root (`http://localhost:18081`), not
  `/dex` — the path-issuer discovery URL composition breaks.
  Docs' example bcrypt hash is invalid ("hashedSecret too
  short"); generate a real one (python `bcrypt` in a uv venv).
- **Dex approval POST**: form has no `action` — POST back to the
  approval URL (carries `?req=&hmac=`). Dex answers 303, not 302.
- Port 8080 on this box is Open WebUI, not free. Dev peer went to
  18080, BFF 19080 (auth) / 19081 (dev-mode), Dex 18081. The
  layer-2/3 harness kills any process holding *its* ports —
  kill your dev peer before running the full routine or 18080
  collides with the smoke.
- `npm create vite` hangs silently in this environment (registry
  fine, scaffold stalls) — grafted the template from the
  `create-vite` tarball instead. `npm install` itself is fast.
