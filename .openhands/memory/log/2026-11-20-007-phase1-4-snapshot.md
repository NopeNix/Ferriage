# Session 007 — Phase 1.4 snapshot (learnings)

- **Docker volume dirs are `root:root 700`** — an unprivileged peer
  process cannot walk `/var/lib/docker/volumes/*`. Volume capture must
  go through the daemon: helper container (volume at `/vol`) + exec'd
  `tar`. This superseded ADR 0002's original "read mountpoint directly"
  plan (which needed root). No sudo available on dev host.
- **Docker attach gotchas (expensive to learn, keep):**
  1. `ContainerAttach` BEFORE `ContainerStart`, else stdout buffers
     deadlock the helper.
  2. Attach-stdin of a not-yet-started container **silently drops**
     client stdin (0 bytes, exit 0, no error). Use a sleeper container
     + `ContainerExecAttach` on a *running* container instead; stdin
     then works.
  3. Exec-attach **stdin is raw**; stdout/stderr come back **framed**
     (demux with `stdcopy.StdCopy`; feed stdin with a plain write to
     `attach.Conn` + `CloseWrite`). Framing stdin leaks the 8-byte
     frame headers into the payload.
- **Volume ownership without labels**: compose labels volumes with
  `com.docker.compose.project`, but peer-restored volumes have no
  labels. Accept label match **or** `<stack>_` name prefix.
- **Go ServeMux**: two handlers both mounting `/` panic at startup.
  Method patterns (`POST /stacks/{name}/export`) on one mux avoid it.
- Snapshot round-trip verified live on home box; ADR 0002 is the spec.
