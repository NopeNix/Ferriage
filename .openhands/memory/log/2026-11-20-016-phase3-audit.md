# Session 016 — audit log (ADR 0008)

- Store is JSONL under `.ferriage/` (sync walker never walks
  it) — no DB, no SQLite view. Bounded by line count with a
  size-proxy prune trigger (`maxLines*64` bytes before
  counting lines) to keep the hot path cheap.
- Middleware captures actor/action/target/status from the
  request/response pair; handlers stay untouched. Onboard
  target is generic ("onboard") because the address lives in
  the body, which middleware must not consume — the peer's
  stdout log already carries it.
- Actor trust: peer is plaintext on the trusted net (ADR
  0004), so `X-Ferriage-Actor` is reported identity, not auth.
  The BFF must strip and re-set it (done in both fetch and WS
  upgrade paths) or a browser could forge another operator's
  entries.
- Two audit entries within the same second sort unstably by
  ts — tests must set-check, not sequence-check.
