# Session 018 — MCP lessons

- **Audit the inner call, not the envelope**: MCP `POST /mcp`
  is mesh machinery; the audited action is the dispatched
  inner request (`deploy`, `exec`, ...). `audit.classify`
  excludes `/mcp` paths; dispatch records via the new
  `audit.Record` with the caller's actor (`mcp` default,
  BFF-stamped when proxied). First live run exposed the
  pollution: five bare `/mcp` lines, no real actions.
- **BFF `/mcp` proxy**: `proxyApi` strips an `/api` prefix,
  so a bare `/mcp` route through it maps to the peer's
  `/mcp` directly. OIDC gate (`auth.checkApi`) applies
  identically — no special-casing needed.
- **MCP tool error vs protocol error**: peer 4xx/5xx →
  `isError: true` tool result (call succeeded, op failed);
  unknown tool/bad args → JSON-RPC `-32602`; unknown method
  → `-32601`. Never crash on a bad agent call.
- **Stateful test peers poison the suite**: a dev peer on
  :18080 left running makes layer-2 peer A fail to bind
  and cascades 6 failures that look like regressions.
  `ss -ltnp` + kill by PID before `test.sh` (same lesson
  from 017, hit again — worth its own line in HANDOVER).
- **Full routine now 53/0** (was 46/0 pre-mcp; +7 = mcp
  tools-list CLI, initialize, tools/call deploy, inner-audit,
  envelope-not-audited, mcp call get_peer, GET /mcp).
